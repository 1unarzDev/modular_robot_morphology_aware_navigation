# Documentation

Start with these documents:

- [Current status](current_status.md): implemented capability, verified
  evidence, active blocker, and exact resumption sequence.
- [Domain model](domain_model.md): canonical research and software terms.
- [Conference roadmap](research/conference_roadmap.md): ordered evidence gates
  from platform qualification through submission artifacts.
- [Statistical analysis plan](research/statistical_analysis_plan.md): frozen
  outcomes, estimands, inference, integrity checks, and power decision.
- [Literature review](research/literature_review.md): primary prior art and
  bounded novelty claim.

Architectural decisions live in [`adr/`](adr/). Dated development diaries were
removed after their durable findings were consolidated into current status,
roadmap, ADRs, tests, and git history.

Generated experiment records and figures belong under ignored `results/`.
Tracked files under `studies/` are prospective designs and manifests, not
observed evidence.
